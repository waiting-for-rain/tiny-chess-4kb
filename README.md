A compact negamax chess engine in Python: alpha-beta search to a fixed node budget, quiescence, null-move pruning and tapered piece-square evaluation, playing the make.fun tiny-chess-01 gauntlet through the env.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 -P -s main.py
```
